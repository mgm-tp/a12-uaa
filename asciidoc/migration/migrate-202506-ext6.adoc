=== 2025.06-ext6

==== Reinstated

===== uaa-authentication

* The attribute `loginTime` of class `JwtTokenData`, together with its getter `getLoginTime()` and the builder method `withLoginTime()`, are no longer deprecated and have been reinstated.
They were previously announced for removal in `2025.06`.
+
`loginTime` now carries the original authentication time (the moment of the first login) and is preserved across token renewals, whereas `issuedTime` reflects when the individual token was issued.
This restores enforcement of `mgmtp.a12.uaa.authentication.jwt.user-lifetime-seconds` when token renewal is enabled.
+
The value is stored in the new `auth_time` token claim. Tokens issued before this change fall back to the token issue time for backward compatibility.
